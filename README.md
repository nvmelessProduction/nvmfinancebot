# nvmfinancebot

Bot di trading sul CRT (Candle Range Theory) di RomeoTPT, costruito come
un'équipe di agenti che imparano, sullo storico e dal vivo, solo quando
dimostrano di fare meglio della regola scritta.

Il progetto è ripartito da zero il 24/09/2026. Il lavoro precedente è
archiviato sul branch `claude/trading-bot-infrastructure-5rht0h`.

## Da dove si comincia

| File | Cosa |
|---|---|
| `STATO.md` | dove siamo, cosa serve adesso, decisioni prese. **Si legge per primo.** |
| `PIANO.md` | l'équipe, come imparano gli agenti, le fasi, le regole del gioco |
| `spec/` | una scheda per agente: la regola scritta con parole semplici |
| `casi/` | i casi annotati dai grafici: il metro con cui si prova il codice |
| `registro/tentativi.md` | ogni prova fatta, anche quelle andate male |
